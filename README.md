## 🌟 The Vision
Amplify is a social advocacy platform designed for NGOs (inspired by the immersive storytelling of the Isha Foundation). It bridges the gap between wanting to help and taking action. We use Generative AI to solve "content fatigue" and real-time database sync to gamify social impact.

## ✨ Key Features

* **🤖 Gemini AI Advocacy Copilot**: Integrates Google Gemini 1.5 Flash to generate personalized, data-driven advocacy visions, removing the creative barrier for volunteers.
* **⚡ Real-Time Impact Tracking**: Built with Firebase Firestore. Watch your referrals flip from **38 to 39** instantly without a page refresh.
* **🔐 Verified Advocacy**: Secure Google OAuth integration ensures every referral and impact point is tied to a real, verified identity.
* **🎨 Immersive UI/UX**: A "Glassmorphism" dashboard featuring high-contrast NGO-style imagery, built for emotional connection and clarity.

## 🛠️ Tech Stack

| Layer | Technology |
| :--- | :--- |
| **Frontend** | React 18 + Vite (Lightning Fast HMR) |
| **Styling** | Tailwind CSS (Modern Utility-First Design) |
| **Backend** | Firebase (Auth & Firestore Real-time DB) |
| **AI Engine** | Google Gemini 1.5 Flash API |
| **Icons** | Lucide-React |
